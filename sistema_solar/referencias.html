Constelaciones oficiales

IAU

Define las 88 constelaciones como regiones oficiales del cielo. Sirve para nombres, abreviaturas y contexto histórico.

iau.org/public/themes/constellations

Límites celestes

CDS / VizieR VI/49

Catálogo de límites de constelaciones. Sirve para dibujar regiones oficiales y determinar a qué constelación pertenece una coordenada RA/Dec.

cdsarc.u-strasbg.fr/viz-bin/Cat?cat=VI/49

Figuras y líneas

Stellarium Sky Cultures

Fuente recomendada para reemplazar trazos aproximados por líneas reales de constelaciones. Incluye culturas celestes modernas, occidentales y tradicionales.

github.com/Stellarium/stellarium/skycultures

Cultura moderna

Stellarium modern_iau

Base práctica para este atlas: líneas modernas compatibles con las 88 constelaciones IAU. Debe transformarse a nuestro formato points y lines.

github.com/Stellarium/stellarium/skycultures/modern_iau

Catálogo estelar simple

HYG Database

Catálogo cómodo para visualizaciones educativas: nombres comunes, coordenadas, magnitud, distancia, color aproximado y referencias cruzadas.

codeberg.org/astronexus/hyg

Fichas astronómicas

SIMBAD / CDS

Base de datos de referencia para objetos fuera del sistema solar. Útil para enriquecer fichas de estrellas, nebulosas, galaxias y quásares.

simbad.u-strasbg.fr/simbad

Astrometría precisa

Gaia Archive

Fuente para posiciones, paralajes, movimientos propios y fotometría moderna. Es la opción más precisa para ubicar estrellas reales.

gea.esac.esa.int/archive

Estrellas visibles

Yale Bright Star Catalogue

Catálogo clásico de estrellas visibles a simple vista, útil para poblar una esfera celeste educativa sin traer millones de objetos.

vizier.cds.unistra.fr V/50

Uso recomendado

Usar Stellarium para las líneas visibles de cada constelación, HYG para estrellas principales y SIMBAD/Gaia para completar fichas de objetos importantes. Los límites oficiales de VizieR VI/49 son otra capa: sirven para regiones celestes, no para la silueta cultural.
