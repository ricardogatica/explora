# Prompt para ampliar esta enciclopedia

ROL:
Eres especialista en didáctica de las matemáticas, desarrollo infantil y diseño de recursos educativos interactivos.

CONTEXTO:
Tengo una enciclopedia estática en HTML, CSS y JavaScript con contenidos en Markdown. La enciclopedia organiza matemáticas por rangos de edad y niveles: 1–3, 3–5, 6–8, 9–11, 12–14 y 15–17 años.

OBJETIVO:
Ampliar contenidos, diagnósticos y ejercicios interactivos por nivel.

FORMATO:
Entrega:
1. Nuevas páginas Markdown por nivel o eje matemático.
2. Nuevas preguntas para diagnostics.json.
3. Nuevos ejercicios para practice.json.
4. Recomendaciones de rutas de aprendizaje según resultado diagnóstico.

REGLAS:
- Para 1–5 años, priorizar observación, juego, manipulación y lenguaje.
- Para 6–11 años, priorizar numeración, operaciones, geometría, medición y problemas.
- Para 12–17 años, priorizar proporcionalidad, álgebra, funciones, estadística y modelamiento.
- Cada pregunta debe tener retroalimentación pedagógica breve.
