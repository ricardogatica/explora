# Números y operaciones

Este eje agrupa cantidad, conteo, numeración y cálculo.

| Edad | Foco |
|---|---|
| 1–3 | uno, dos, muchos, comparación |
| 3–5 | conteo, cantidad, números escritos |
| 6–8 | valor posicional, suma, resta, multiplicación inicial |
| 9–11 | multiplicación, división, fracciones, decimales |
| 12–14 | enteros, racionales, porcentajes, proporcionalidad |
| 15–17 | expresiones algebraicas, ecuaciones, sistemas |

## Errores frecuentes

- Recitar números sin contar objetos correctamente.
- Confundir el valor de una cifra según su posición.
- Aplicar algoritmos sin comprender el problema.
- Creer que una fracción con denominador mayor siempre es mayor.
