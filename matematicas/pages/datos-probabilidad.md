# Datos y probabilidad

Este eje permite organizar información, interpretarla y tomar decisiones basadas en evidencia.

| Edad | Foco |
|---|---|
| 1–3 | clasificar objetos |
| 3–5 | ordenar y agrupar |
| 6–8 | pictogramas y tablas simples |
| 9–11 | gráficos de barras y conteos |
| 12–14 | promedio, mediana, moda y rango |
| 15–17 | probabilidad, dispersión y análisis de datos |

## Errores frecuentes

- Confundir frecuencia con porcentaje.
- Leer gráficos sin revisar la escala.
- Usar promedio cuando la mediana representa mejor los datos.
- Creer que un evento poco probable es imposible.
