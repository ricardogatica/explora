# Geometría y medición

Este eje desarrolla comprensión del espacio, formas y magnitudes.

| Edad | Foco |
|---|---|
| 1–3 | dentro/fuera, arriba/abajo, formas simples |
| 3–5 | círculo, cuadrado, triángulo, comparación de tamaños |
| 6–8 | figuras 2D, cuerpos 3D, medición con unidades simples |
| 9–11 | perímetro, área, ángulos y simetría |
| 12–14 | propiedades de figuras, volumen y escalas |
| 15–17 | geometría analítica y trigonometría básica |

## Errores frecuentes

- Confundir área con perímetro.
- Medir sin unidad.
- Creer que una figura cambia de nombre al rotarla.
- Aplicar fórmulas sin identificar las dimensiones correctas.
