# Patrones y álgebra

El álgebra comienza mucho antes de usar letras. Parte con reconocer regularidades y anticipar lo que sigue.

| Edad | Foco |
|---|---|
| 1–3 | imitación de secuencias simples |
| 3–5 | patrones AB y AAB |
| 6–8 | patrones numéricos simples |
| 9–11 | relaciones multiplicativas |
| 12–14 | variables y ecuaciones lineales |
| 15–17 | funciones, sistemas y modelos |

## Habilidades clave

- Reconocer lo que se repite.
- Completar secuencias.
- Describir reglas.
- Usar símbolos para representar cantidades.
- Resolver ecuaciones.
- Interpretar funciones y gráficos.
