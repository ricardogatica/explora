# Tilde diacrítica

La tilde diacrítica se usa para diferenciar palabras que se escriben igual, pero tienen funciones o significados distintos.

## Pares frecuentes

| Con tilde | Sin tilde |
|---|---|
| **tú**: pronombre personal | **tu**: posesivo |
| **él**: pronombre personal | **el**: artículo |
| **mí**: pronombre personal | **mi**: posesivo o nota musical |
| **sí**: afirmación o pronombre | **si**: conjunción condicional |
| **té**: bebida | **te**: pronombre |
| **dé**: forma del verbo dar | **de**: preposición |
| **sé**: forma de saber o ser | **se**: pronombre |
| **más**: cantidad | **mas**: equivalente a “pero” |

## Ejemplos

- **Tú** tienes **tu** cuaderno.
- **Él** abrió **el** libro.
- Lo compró para **mí**, no para **mi** hermano.
- Dijo que **sí** vendría, **si** terminaba temprano.
- Quiero un **té**; luego **te** llamo.
- Espero que me **dé** una respuesta.
- **Sé** responsable; no **se** permite gritar.
- Necesito **más** tiempo, **mas** no puedo quedarme.

## Nota sobre “solo” y demostrativos

Actualmente, la palabra **solo** y los demostrativos **este, ese, aquel** y sus variantes no llevan tilde de forma general. La recomendación académica es prescindir de la tilde incluso en casos de posible ambigüedad, salvo situaciones muy excepcionales.
